# 图片占位清单

> 设计约束（记忆 image-placeholder-policy / 设计规格 §14）：项目不生成真实图片，一律名称占位。
> 请按以下清单准备图片，**同名替换**即可，前端零改动。

## 基础图片（骨架阶段）

| 占位名 | 用途 | 建议格式 | 建议尺寸/大小 |
|--------|------|----------|---------------|
| `site-logo` | 站点 Logo（导航栏） | PNG（透明底） | 192×192，≤100KB |
| `site-avatar` | 站点头像（Hero/关于页，后续用到） | JPG/PNG | 512×512，≤200KB |
| `hero-bg` | 首页 Hero 背景图（后续接入） | JPG/WebP | 1920×1080，≤500KB |
| `favicon` | 浏览器标签图标 | PNG/ICO | 32×32 + 192×192 |

## 功能图片（对应功能落地时再出）

| 占位名 | 用途 | 建议格式 | 建议尺寸/大小 |
|--------|------|----------|---------------|
| `cover-{slug}` | 文章封面（每篇独立） | JPG/WebP | 1200×630，≤300KB |
| `friend-{name}` | 友链头像 | PNG/JPG | 96×96，≤50KB |

## 说明

- 未提供的图片前端显示 .img-placeholder 占位样式（淡蓝粉渐变底 + 名称文字），不报错
- 图片放本目录，同名替换即可生效
